# Banking.ru

Соревновательный бенчмарк банковской поддержки на базе τ-bench. Цель — создавать
реалистичные русскоязычные задачи, для которых агентам недостаточно простых
стратегий. Агент получает обращение клиента и работает с банковскими системами.
Оценка учитывает конечное состояние банка и выполнение требуемых действий
(`DB × ACTION`).

## Быстрый старт

Клонируйте этот репозиторий и запустите структурную проверку. Нужны Git,
`make` и Python 3.10 или новее, доступный как `python3`.

```sh
git clone https://github.com/SpirinEgor/agent-evaluation.git
cd agent-evaluation
make check-banking-repo
```

Проверка сверяет ссылки и якоря документации, индекс задач, профили оценки
и входы поддерживаемых тестов. При успехе вывод начинается с
`Banking repository OK`. При ошибке скрипт указывает проблемный файл или задачу.

### Проверка транспорта A2A

Для тестов нужны Python 3.12 или 3.13, `uv` и `ripgrep` (`rg` в PATH).
Следующая команда проверяет обмен с агентом-заглушкой, включая доставку тикета,
вызов инструмента и получение результата.

```sh
uv sync --frozen --extra dev --extra platform
uv run pytest tests/test_platform/test_codex_a2a.py::test_setup_results_final_receipt_and_no_direct_mcp -q
```

Обе проверки работают без модели, API-ключей и установки Codex.
