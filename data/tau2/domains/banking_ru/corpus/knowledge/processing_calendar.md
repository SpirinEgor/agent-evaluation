# Дата сценария и обработка переводов

Документ: операционный календарь учебного банка. Редакция: 2026-10-14.
Применяется ко всем обращениям текущего банковского набора, без исключений по ID задачи.

## Дата банка

Текущую дату зафиксированного сценария получите через банковский календарь или из
явно датированного обращения. Для оценки просрочки используйте дату сценария,
а не время компьютера или запуска модели.
Это дата учебной среды, а не утверждение о реальной сегодняшней дате.

## Источник срока

Получите свою операцию по полной истории операций либо карточке операции.
Поле date — дата создания записи; debited_at — дата фактического списания.
payment_route задаёт механизм: card_to_card, sbp или account_details.
expected_completion_date — ожидаемая крайняя дата исполнения, полученная из процессинга
по конкретному маршруту. Используйте её, не прибавляйте автоматически три дня к date.
Для банковского календаря учитываются рабочие дни; выходные сами по себе не являются задержкой.
Ожидаемая дата — ориентир процессинга, а не гарантия зачисления и не универсальный срок закона.
Если маршрут, списание или ожидаемая дата отсутствуют, не выдумывайте их: требуется диагностика.

## Статус и дальнейшее действие

processing означает обработку; этот статус не доказывает ни зачисление, ни возврат.
До ожидаемой даты признаки просрочки по одному лишь processing не установлены.
После ожидаемой даты либо при ошибке маршрута требуется сверка исполнения.
Обычный карточный маршрут нельзя переносить на СБП: длительный processing СБП требует диагностики.
Сопоставьте сумму, получателя, дату и статус, чтобы не перепутать новую операцию с прежней posted.
Не создавайте новый перевод, возврат, разблокировку или спор без соответствующего поручения и основания.
В completion_only получите сведения и завершите обслуживание: итог клиенту не отправляется.

## Граница моделирования

Это учебный процесс первой линии условного банка, а не обещание конкретного банка России.
Законные предельные сроки зависят от механизма и момента списания; этот документ не меняет их.
Задача проверяет получение объявленных сведений процессинга, а не невысказанный вывод агента.
